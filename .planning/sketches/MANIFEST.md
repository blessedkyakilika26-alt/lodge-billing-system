# Sketch Manifest

## Design Direction
Professional desktop billing lab for a university lecture (ICT261, Mulungushi University).
The reference mockup shows a clean blue "boardroom" design: blue header bar, icon toolbar,
light-blue price info panel, striped bills table, green success status. The user wants a
wide exploration of color while keeping typography clean and neutral (Segoe UI family,
Windows system fonts only, since the real app is JavaFX on Windows).

## Reference Points
- User-provided mockup image: blue header bar with File/Help menus, icon toolbar
  (New guest / View receipt / Delete selected bill), form + price panel two-column layout,
  striped "Saved bills" table, green success status line.

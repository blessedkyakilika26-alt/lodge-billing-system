# Sketch 001: Style Identity

## Design Question
Which color palette and typographic treatment should the Lodge Billing Lab use?
The user's reference is a clean blue corporate design; they asked for a wide range
of color options with clean, neutral typography (Windows system fonts only, since
the real app is JavaFX).

## How to View
open .planning/sketches/001-style-identity/index.html

## Variants
- **A: Boardroom Blue** — the reference refined: Segoe UI throughout, tabular numerals, focus rings, tighter spacing.
- **B: Safari Lodge** — warm hospitality palette (terracotta / cream / wood) with Candara display headings and generous radii.
- **C: Midnight Ledger** — dark slate with teal accent; Consolas for money figures; balance column colored (amber = owed, green = settled).

## What to Look For
- Which palette feels right for a university lab demo that should still look "real"?
- Money figures: right-aligned tabular numerals (all variants); Consolas digits in C vs Segoe in A/B.
- The colored Balance column in C — helpful signal or noise?
- Radii and softness: A is crisp (8px), B is soft (12px), C is sharp (6px).
- All three screens are fully interactive: Calculate and Save bill actually compute (350/550/750 rates, 5% discount at 5+ nights), rows select and delete.
